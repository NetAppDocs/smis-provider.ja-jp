= NetApp SMI-S プロバイダの起動に時間がかかります
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
NetApp SMI-S Provider は、既に管理されているストレージシステムを備えた Windows システムでは起動に最大 15 分かかる場合があります。これは、 `smis cimserver` コマンドがプロバイダのローカルキャッシュが読み込まれるまで待機するためです。 `smis cimserver` コマンドを使用してください。このコマンドはプロバイダを起動するための推奨方法であり、プロバイダが利用可能になるまでに遅延が発生することをご了承ください。

* * 概要 *
+
すでに管理中のストレージシステムを使用している Windows システムでは、「 SMIS cimserver 」コマンドを使用して NetApp SMI-S Provider を起動した場合、プロバイダのローカルキャッシュが読み込まれるまでコマンドは返されません。キャッシュが読み込まれるまで最大 15 分待機し、 NetApp SMI-S プロバイダを使用することはできません。

+
NetApp SMI-S Provider の起動には 'SMIS cimserver コマンドを使用することをお勧めします
